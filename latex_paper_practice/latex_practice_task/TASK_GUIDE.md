# 最小论文全流程练习任务

## 一、题目

**基于一元线性回归的气温与冷饮销量关系分析**

某校园冷饮店记录了连续 15 天的日最高气温与冷饮销量。请分析气温和销量之间是否存在明显关系，并建立一个最简单的一元线性回归模型，用气温解释或预测销量。

这是一项排版与建模流程练习，不追求复杂模型。你的目标是独立走完：

> 读取数据 → 检查数据 → 描述统计 → 相关分析 → 建立模型 → 检验模型 → 绘图 → 绘制流程图 → 填写论文 → 在 Overleaf 编译

## 二、已有文件

- `main.tex`：可以直接编译的最简中文论文模板。
- `data/daily_sales.csv`：已知数据。
- `analysis.py`：Python 分析框架，需要你补充 TODO。
- `figures/README.md`：需要生成的图片及命名规则。

## 三、你需要完成的分析

### 1. 数据读取与检查

读取 `data/daily_sales.csv`，回答：

1. 数据有多少行、多少列？
2. 是否存在缺失值？
3. 气温和销量是否存在明显不合理值？

本练习的数据是完整数据，不需要为了展示“数据清洗”而故意删除或修改数据。确认没有缺失值和明显异常后，直接保留全部样本。

### 2. 描述性统计

分别计算气温和销量的：

- 均值；
- 标准差；
- 最小值；
- 最大值。

把结果填入 `main.tex` 的表 2。

### 3. 相关分析

计算气温与销量的 Pearson 相关系数，并解释：

- 正负号表示什么；
- 绝对值大小说明什么；
- 相关关系是否等于因果关系。

### 4. 建立一元线性回归模型

令：

- `x`：日最高气温，单位为摄氏度；
- `y`：当日冷饮销量，单位为杯。

建立模型：

```text
y = beta_0 + beta_1 * x + epsilon
```

使用 `numpy.polyfit(x, y, 1)` 求斜率和截距，写出最终拟合方程，并解释斜率的实际意义。

### 5. 模型评价

计算：

- 决定系数 R²；
- 均方根误差 RMSE。

本练习的自检范围：相关系数应大于 0.99，斜率应为正且大约在 4 附近，R² 应大于 0.99。若结果偏差很大，应先检查变量顺序和公式。

### 6. 绑制结果图

用 Matplotlib 绘制：

- 原始数据散点；
- 同一坐标系中的拟合直线；
- 横轴为气温，纵轴为销量；
- 图例区分“观测数据”和“拟合直线”。

保存为：

```text
figures/scatter_fit.pdf
```

必须使用 `bbox_inches="tight"`，避免插入论文后四周空白过大。

### 7. 绘制流程图

使用 draw.io 绘制下列过程：

```text
开始
  ↓
读取 CSV 数据
  ↓
是否存在缺失值或明显异常？
  ├─ 是 → 数据清洗 ─┐
  └─ 否 ───────────┤
                   ↓
计算描述性统计与相关系数
  ↓
建立一元线性回归模型
  ↓
计算 R² 和 RMSE
  ↓
绘制拟合结果图
  ↓
得到结论
```

其中“是否存在……”使用菱形，其余计算步骤使用矩形，开始与结束使用圆角矩形。导出时选择 PDF 并勾选裁剪，命名为：

```text
figures/workflow.pdf
```

### 8. 完成论文

搜索 `main.tex` 中所有 `【填写】`，依次替换为你的结果或解释。不要只填数字，还要完成结果的实际含义解释。

## 四、论文中每部分应写什么

| 部分 | 要写的内容 |
|---|---|
| 摘要 | 研究对象、数据、方法、核心结果、结论 |
| 问题重述 | 已知什么、需要解决什么 |
| 数据分析与预处理 | 变量含义、数据规模、缺失值、描述统计 |
| 模型建立 | 变量、模型公式、参数含义、求解方法 |
| 结果分析 | 回归方程、相关系数、R²、RMSE、结果图解释 |
| 结论与不足 | 得到的结论、模型用途、相关不等于因果、小样本局限 |
| 附录 | Python 核心代码 |

## 五、Overleaf 操作顺序

1. 将整个 zip 上传到 Overleaf 并解压为项目。
2. 确认主文件为 `main.tex`。
3. 在项目设置中把编译器改为 **XeLaTeX**。
4. 第一次直接编译。此时缺少两张图片，模板会显示占位框，但不应报错。
5. 完成 `analysis.py` 并运行，得到 `figures/scatter_fit.pdf`。
6. 使用 draw.io 生成 `figures/workflow.pdf`。
7. 将两张 PDF 上传到 Overleaf 的 `figures` 文件夹。
8. 替换 `main.tex` 中全部 `【填写】`。
9. 再次编译，检查图题、表题、公式编号、正文引用和页面空白。
